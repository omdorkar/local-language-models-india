## How to read this file

* **Primary** sections (H1-H5) are the five main hypothesis tests described in the paper's Methods and nothing else. Every test is shown whether or not it is significant.
* Cells show the paired accuracy gap in percentage points (condition minus reference; for H3 the Spearman rho) followed by the verdict: ✓ confirmed (Holm-adjusted p < 0.05 and gap in the predicted direction), ✗ not confirmed, ⚠ significant but in the opposite direction, `not run` = no data for that test.
* Holm correction is applied separately inside each hypothesis family, over the fixed-size family (5 models x languages); tests that could not run count as p = 1.
* Gaps are accuracy(condition) - accuracy(reference) on the same items; invalid answers count as wrong. CIs, p-values, b/c discordant counts and n are in `confirmatory.csv`.
